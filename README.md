# 🧠 Brain Tumor Detection using Convolutional Neural Networks (CNN)

## 📌 Project Overview

Brain Tumor Detection using CNN is a deep learning project that automatically detects brain tumors from MRI images. The system uses a Convolutional Neural Network (CNN) to classify MRI scans accurately, assisting healthcare professionals in early diagnosis and reducing the time required for manual analysis.

---

## 🎯 Objectives

* Detect brain tumors from MRI images using deep learning.
* Improve diagnostic accuracy through image classification.
* Reduce manual effort in medical image analysis.
* Develop a scalable and user-friendly prediction system.

---

## ✨ Features

* MRI image preprocessing and normalization.
* CNN-based image classification.
* High-accuracy tumor detection.
* Real-time prediction for uploaded MRI images.
* Easy-to-use interface (optional Streamlit/Flask deployment).

## 🔄 Workflow

1. Collect MRI image dataset.
2. Preprocess images (resize and normalize).
3. Train the CNN model.
4. Validate and test the model.
5. Predict tumor presence from new MRI images.
6. Deploy the trained model.

---

## 🧠 CNN Architecture

* Input Layer
* Convolution Layer
* ReLU Activation
* Max Pooling Layer
* Dropout Layer
* Fully Connected Layer
* Softmax/Sigmoid Output Layer
